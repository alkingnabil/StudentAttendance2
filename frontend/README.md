# منصة تدريبي — النسخة الأخيرة

نسخة ويب تفاعلية تعمل محليًا باستخدام LocalStorage، مع استيراد Excel فعليًا داخل المتصفح.

## دخول الإدارة

الحسابات الإدارية التجريبية:

- مي عبداللطيف: `mai@tadreebi.local` / `123456`
- مصطفي الزناتي: `mostafa@tadreebi.local` / `123456`
- أبو الحسن ربيع: `abohassan@tadreebi.local` / `123456`
- بدور سلطان: `bodour@tadreebi.local` / `123456`
- هاني يسن: `hani@tadreebi.local` / `123456`
- Master: `master@tadreebi.local` / `master123`

تم ضبط مجموعات مي عبداللطيف افتراضيًا على: 1، 6، 11، 21.

حساب Master فقط يرى كل المجموعات ويستطيع تعديل مجموعات حسابات الإدارة.

## الوظائف

- الطلاب لا يستطيعون إنشاء الحساب إلا إذا كان الاسم ورقم الجلوس موجودين في بيانات Excel.
- كود الطالب 3 أرقام.
- الحضور بالكود أو QR.
- لوحة الإدارة تعرض سجل الحضور لليوم الحالي فقط؛ السجل التاريخي يظل محفوظًا ويظهر في إحصاءات الطالب.
- التقييم يبدأ بجلسة تحدد الشهر والتاريخ والدرجة النهائية مرة واحدة.
- شهر التقييم يتم اختياره من شهور الدراسة التي حددتها الإدارة.
- شهور الدراسة قائمة من يناير إلى ديسمبر مع زر تعديل.
- بيانات الأماكن والمجموعات قابلة للتعديل من لوحة البيانات.
- التنشيط يبحث بالرقم القومي ويعرض الاسم ورقم الجلوس ثم زر تنشيط.
- حسابات أعضاء الهيئة المعاونة محصورة في مجموعاتهم.
- Master يستطيع التعامل مع كل الدفعات وإعداد البيانات والتصدير.
- الاستيراد يدعم XLSX/XLS/CSV عبر مكتبة SheetJS المضمنة من CDN عند الاتصال بالإنترنت.

## التشغيل

افتح `index.html` مباشرة للوظائف الأساسية. لتشغيل الكاميرا، شغل المجلد عبر localhost أو HTTPS.

> ملاحظة: هذه نسخة Front-End محلية؛ البيانات محفوظة في متصفح الجهاز وليست قاعدة بيانات مركزية. للنشر الحقيقي متعدد الأجهزة نحتاج Backend وقاعدة بيانات وحسابات آمنة.
